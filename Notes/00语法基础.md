## 变量

在 Rust 中，数据类型表示如下：

| 类型名                     | 表示方式                           |
| ----------------------- | ------------------------------ |
| Signed integers 有符号整数   | i8, i16, i32, i64, i128, isize |
| Unsigned integers 无符号整数 | u8, u16, u32, u64, u128, usize |
| Floating point 浮点数      | f32, f64                       |
| Unicode 字符型             | char                           |
| Boolean 布尔型             | bool                           |

### 变量定义

Rust 中使用关键字 **`let`** 来给变量定义和赋值。

**1.直接赋值**

```rust
let x = 1;  //rust中允许不声明类型, 编译器可以通过上下文来推断数据类型
```

**2.显式指定类型**

```rust
let x:u32 = 1;  
```

**3.后缀指定类型**

```rust
let x = 1u32;  
```

### static与const

`let`一般用于定义**运行时的局部变量**，而**全局静态变量和常量则使用`static`和`const`定义**。

`const`：编译期常量

```rust
const MAX: u32 = 100;
const PI: f64 = 3.14159;
```

`static`：全局静态变量

```rust
static GREETING: &str = "Hello";
static mut COUNTER: u32 = 0; // 访问需 unsafe

fn main() {
    println!("{}", GREETING);
    unsafe {
        COUNTER += 1;
    }
}
```

- 初始化必须是常量表达式。

- 默认不可变，可以使用关键字`static mut` 使其可变，但访问还需要添加 `unsafe`，表明知晓正在进行不安全操作(容易引发数据竞争)。

但是rust并不推荐使用`unsafe`，在实际实践中应尽量避免。在后续学习中会接触到更安全的全局变量操作。

### 可变变量

在 Rust 中，变量都是默认不可变的，下示代码在编译时会报错：

```rust
let x = 1;
x = 2;    // × 编译报错 
```

对于可以修改的变量，Rust 要求使用关键字 **`mut`** 显式声明：

```rust
let mut x = 1;
x = 2;    // √ 正确写法
```

### 变量遮蔽

Rust 允许重用变量名，这个特性称之为 **遮蔽（Shadowing）**。

如下代码所示，当出现同名变量时，新的变量会把旧的变量遮蔽，直到新变量的作用域结束，被遮蔽的变量才得以恢复正常使用。

```rust
    let a = 1;
    {
        let a = 2;
        println!("{a}");    // 打印结果为2        
    }
    println!("{a}");    // 打印结果为1

    let a = 3;
    println!("{a}");    // 打印结果为3
```

遮蔽特性的实质是在不更改变量名的情况下创建新的变量，因此可以在类型或数值上进行修改。

```rust
    let a = 1;
    println!("{a}");    // 打印结果为1

    let a = "Hello, world!";    
    println!("{a}");    // 打印结果为Hello, world!
```

## 函数

Rust 中的所有函数都以关键字 **`fn`** 开头，可执行文件的默认入口点是 `main()`。

函数的传入参数需显式声明类型，有返回的值的需要用 `->` 加数据类型表明，如下代码所示：

```rust
fn add(a: i32, b: i32) -> i32 {
    a + b   // 等价于 return a + b;
}

fn main() {
    let result = add(5, 3);
    println!("The sum is: {}", result);
}
```

函数内的最后一行在不以分号结尾的情况下会被视作表达式进行返回，相当于 `return`。

## 所有权

所有权特性是 Rust 为了避免程序员手动管理内存而引发内存安全问题设计的。每个数据都只能被一个对象所持有，这就是数据的所有权。

当数据被赋值、传入函数或返回时，所有权也会发生移交（语义移动），该数据就失效了，后续不能再被使用。

这种设计是为了避免两个指针指向同一块内存或重复释放等内存安全问题，很显然，这是特别为堆上数据和指针数据设计的（但所有权规则适用于所有数据），所以对于栈上的标量数据如整型、浮点数、布尔型等，在使用时的所有权变化**是语义复制而不是语义移动**，相当于创建出一个新的变量，所以标量数据即使被使用了，后续还是可以继续使用。

以下面代码为例：

```rust
fn main() {
    let x = 42;          
    let y = x;           // 语义复制，x仍可使用
    println!("{} {}", x, y); // √ 可正常编译

    let s1 = String::from("hello"); // String 属于指针数据
    let s2 = s1;         // 语义移动，s1所有权移动到s2，s1失效，不可使用
    println!("{}", s1);  // × 编译错误！使用了失效的s1
}
```

## 模块与Crate

模块(Module)，每一个 `.rs` 文件本身就是一个隐式的模块，在该模块文件中还可以通过关键字 **`mod`** 进行模块的定义与嵌套。

模块将功能相关的函数方法和数据类型组织在一起，类似于C语言的头文件，并可以通过关键字 **`pub`**（public）来控制其对外可见性，默认情况下模块内部代码都是私有的，对外不可见。

### 模块定义

模块的定义示例代码如下：

```rust
mod math {
    // 对外可见的函数方法
    pub fn add(a: i32, b: i32) -> i32 {
        a + b
    }
}

fn main() {
    let sum = math::add(2, 3);        // 通过路径调用
    println!("{}", sum);
}
```

上述示例是同一 `.rs` 文件中即内部模块的定义与使用，而外部模块的声明和使用示例如下：

```rust
// 项目结构中有两个 .rs 文件
src/
├── main.rs
└── mods.rs

// mods.rs    直接编写模块内容即可，.rs 文件本身就是一个隐式的模块
pub fn greet() {
    println!("Hello!");
}

// main.rs
mod mods;    // 声明外部模块 mods

fn main()
{
      mods::greet();     
}
```

### 模块调用

在使用模块前，必须使用 `mod`进行声明。而在调用其函数时，需写清楚其路径，假设 mods 模块中还定义了一个模块`mod1`，`greet()`是 `mod1` 内部的函数，则调用路径为 `mods::mod1::greet()`。

显然，每次调用都把路径完整写出来很烦琐，所以 Rust 中还可以使用关键字 **`use`** 来简化路径。

```rust
// 使用 mod 声明：告诉编译器加载 mods.rs，这一步是必须的，否则 Rust 根本不知道有 mods 这个模块。
mod mods;

// 使用 use 把模块内容引入当前作用域，这一步是可选的，不写也能用完整路径调用。
use mods::mod1::greet;

// use 可以搭配 as 来给模块内容定一个别名
use mods::mod1::greet as SAYHELLO;

fn main() {
    // 1.不用 use，完整路径调用
    mods::mod1::greet();     // 能用，但每次都要写完整路径

    // 2.使用 use，直接调用
    greet();     // 简化路径，等价于上面

    // 3.使用 use as，直接调用别名
    SAYHELLO();        //等价于上面         
} 
```

### Crate

**crate是rust的编译单元**，**一个 crate 由一个根文件（如`lib.rs` / `main.rs`）和它通过 `mod` 声明的若干子模块文件共同组成。** crate可以理解为“依赖的软件包”或“C语言中的库”，但不同于C语言的库需要手动下载到本地再引用，在 Rust 里，crate主要由官方社区管理分发，如想使用，只需要在 `Cargo.toml` 里声明依赖，Cargo 就会自动从官方仓库 [crates.io](https://crates.io/) 拉取、解析版本、编译并链接。

`mod`是用于**声明和调用本地自己写的模块**，而对于**外部的crate则不需要用 `mod` 声明**，因为它们是通过 `Cargo.toml` 的 `[dependencies]` 引入的，可以直接通过`use`使用。

在嵌入式开发中，很多常用外设模块的驱动库都可以在[crates.io](https://crates.io/)查找或直接声明依赖来引用，在后面的章节中我们也会学习到。

## 控制结构

### 条件分支

在 Rust 中，`if/else` 结构实际是一个表达式，因此可以带有返回值，在行为上又可以作为语句使用。

在常规用法上跟 C 语言相似，需注意的是条件必须是 `bool` 类型，不能像 C 语言那样使用 0 和 1。

在返回值的用法上，如下代码所示：

```rust
let value = if condition { 1 } else { 2 };    //条件成立则返回1并赋值给value, 否之返回2
```

需要注意的是，所有分支的返回值类型必须是一样的，否则编译报错；`if/else` 结构进行返回值操作时，必须带有分号，在整个结构的结尾才能被视作表达式，否则只是一个逻辑控制语句。

### 循环

Rust 中的循环结构有 `while`、`loop` 和 `for`。

其中 `while` 循环的用法与 C 语言相似，不多说明；`for` 在用法上也与 C 语言相似，遍历范围用 `A..B` 表示，示例代码如下：

```rust
fn main() {
    for x in 1..10 {
        println!("{}", x); //依次打印出1-9, 1..10不包括最后一位数, 如果要连10一起, 则范围应表示为1..=10
    } 
}
```

`loop` 循环和大多数语言一样，用 `continue` 跳过本次循环的剩余部分，直接开始下一轮；在遇到 `break` 时退出，但是 `break` 时可以将一个表达式作为返回值返回给 `loop`，如下代码：

```rust
fn main() {
    let mut counter = 0;
    let result = loop {
        counter += 1;
        if counter == 10 {
            break counter * 2; // 跳出循环，并把 counter*2 的值（20）带出去
        }
    };
    println!("{}", result); // 输出 20
}
```

除此之外，在处理 `loop` 的循环嵌套时，还有循环标签。在多层循环时，`break` 和 `continue` 默认只作用于最近的那一层。如果想跳出外层循环，可以通过循环标签实现。

通过`'标签: loop`给一层循环打上标签，再通过 `break '标签` 或 `continue '标签` 来精确控制跳出哪一层循环，如下代码所示：

```rust
fn main() {
    let mut x = 0;
    'outer: loop {    // 这是外层循环, 通过'outer打上标签 
        let mut y = 0;
        loop {    // 这是内层循环
            if y == 5 {
                break 'outer; // 直接跳出外层循环，终止所有循环
            }
            y += 1;
        }
        x += 1;
    }
    println!("跳出所有循环！");
}
```

## 数据结构

**1. 数组**

定义方法如下所示，在默认情况下也是不可修改的，除非使用 `mut`，此外可以使用 `len()` 方法获取数组的长度。

```rust
    let arr : [u8; 3] = [0; 3];        // 数组成员全部为0且不可修改
    let mut arr : [i32; 3] = [1, 2, 3];        
    arr[0] = 0;                
    println!("{}", arr[0]);        // 输出0
    let arr_len = arr.len();
    println!("{}", arr_len);    // 输出3    
```

**2. 元组**

元组与数组类似，但是可以由不同数据类型组成，如下所示：

```rust
    let person : (String, i32, bool) = ("Alice".to_string(), 30, true);
    let name = person.0; // 通过索引访问
    let (name, age, active) = person; // 解构
```

**3. 引用（指针）**

Rust 中的引用类似于 C 语言中的指针，用符号 `&` 表示。如下所示：

```rust
fn main()
{
    let a = 42;
    let b = &a;
    let c = b;

    print!("{} {}", b, c);      // 传递的是引用(也就是地址)，编译时会自动解引用，输出42 42  
    print!("{} {}", *b, *c);    // 手动解引用，输出42 42
}
```

在 Rust 中，`&` 引用的特性是可以实现数据的只读访问而不获取其所有权，这也被称之为**借用**。

对于引用，也可以分为**不可变引用`&`**和**可变引用 `&mut`**。在rust的借用规则中，**一个值的不可变引用`&` 和可变引用 `&mut` 不能同时存在**。原因显而易见，防止对一个值同时进行读与写而导致的数据竞争，这个规则使rust在语法上就杜绝了这种可能。

对于不可变的值，只能进行不可变引用，对于可变的值允许存在一个可变引用或多个不可变引用。

对于可变值，进行可变引用时，本质上跟C语言的指针是一样的。但是在进行不可变引用时，不可变引用存在期间，该可变值不可进行修改，必须要等到不可变引用被使用即生命周期结束后，才能进行修改。如下代码所示：

```rust
let mut x = 5;
let y = &x;      // y 借用 x

// x = 100；    // ×编译报错，此时 x 不能修改，因为 y 还活着

println!("{}", y); // 打印 5

// 后续代码中不再使用y，y的生命周期结束，现在可以修改 x
x = 100;

// 重新取一个新的引用 y2
let y2 = &x;

println!("{}", y2); // 打印 100
```

**注意**：关于上述示例中，`y`的生命周期在不同版本的rust中并不一致。2018版之前的rust，引用的生命周期严格遵循代码块的`{}`作用域，在离开作用域后才能修改被引用的值。而2018版及以后的rust特性，把引用的最后使用位置视作生命周期的结束点，正如上方示例所示。

**4. 字符串**

Rust 中最常用的字符串类型有两个： `&str` 和 `String` 。前者是字符串字面量/字符串切片，后者是自有字符串/动态字符串。

`String` 类型字符串是堆上的、可增长的、拥有所有权的字符串，需要内存分配器，可以随意操作（添加、删除、替换），动态大小，可在运行时增长。

`&str` 类型很显然是 `&` 引用，借用字符串而没有所有权，所以对数据只读而不能进行操作，在编译时大小就是固定且确定的，被直接放进二进制文件的只读数据段，不需要堆分配。对嵌入式`no_std` 场景来说， `&str` 字面量是绝对主力。

```rust
let msg = "message";    // &str类型字符串
msg.push_str("!");        // ×编译报错，&str只读，不可操作


let msg = "message".to_string();    // String类型字符串
let msg = String::from("message");    // 等价于上一行代码
msg.push_str("!");                    // √正常编译，`String` 类型字符串可以修改
```

**5. 结构体**

结构体的代码示例如下：

```rust
    struct Person {
        name: String,
        age: u32,
    }

    let a = Person {
        name: String::from("3YJACK"),
        age: 30,
    };
```

除了常规结构体，还有元组结构体，其成员没有名字，常用于封装单一类型，如下所示：

```rust
    struct Color(i32, i32, i32); // RGB
    let black = Color(0, 0, 0);
```

结构体除了有数据成员之外，还可以关联函数，类似于C++的抽象，对象可以有属性和方法。

函数关联通过 **`impl`+ 结构体 + 代码块**来实现，关联的函数包括方法（参数中有 `self`）和普通关联函数（参数中无 `self`）。如下代码所示：

```rust
    struct Person {
        name: String,
        age: u32,
    }

impl Person {
    // 关联函数，不使用self，通过 Person::new() 调用
    fn new(name: &str, age: u32) -> Self {
        Person {
            name: String::from(name),
            age,
        }
    }

    // 方法，使用self，通过 person.greet() 调用，这里使用的是&self即借用，数据只读且所有权不移动
    fn greet(&self) {
        println!("Hello, my name is {} and I am {} years old.", self.name, self.age);
    }

    // 方法，使用self，通过 person.have_birthday() 调用，这里使用的是&mut self即借用，数据可修改且所有权不移动
    fn have_birthday(&mut self) {
        self.age += 1;
        println!("Happy Birthday! Now I am {} years old.", self.age);
    }

    // 方法，使用self，通过 person.passaway() 调用，这里使用的是self即移动，数据可修改且所有权移动到方法passaway，self离开方法作用域后自动释放，无法再使用
    fn passaway(self) {
        println!("{} has passed away.", self.name);
        }
}
```

**6.枚举**

Rust 中的枚举类似于结构体，允许由不同类型的成员组成且成员可以携带数据。

枚举通常与模式匹配 `match` 联合使用，用法类似于 `switch`，如下代码所示：

```rust
fn main() {
    enum Numbers {
        Zero,
        SmallNumber(u8),
        BiggerNumber(u32),
        EvenBiggerNumber(u64),
    }

    let b = Numbers::SmallNumber(42);
    match b {
        Numbers::Zero => println!("Zero"),
        Numbers::SmallNumber(value) => println!("Small number {value}"),
        Numbers::BiggerNumber(_) | Numbers::EvenBiggerNumber(_) => println!("Some BiggerNumber or EvenBiggerNumber"),
    }

    if matches!(b, Numbers::Zero | Numbers::SmallNumber(_)) {
        println!("Matched Zero or small number");
    }
}
```

## 泛型

**泛型（Generics）是“写代码时不指定具体类型，等到使用时再填入具体类型”的机制。** 它的目标是：**一份代码，适配多种类型，同时保持类型安全，且没有运行时开销。**

以比大小的函数为例，如果是C语言中，没有泛型的情况下：

```c
fn max_i32(a: i32, b: i32) -> i32 { if a > b { a } else { b } }
fn max_f32(a: f32, b: f32) -> f32 { if a > b { a } else { b } }
fn max_u8(a: u8, b: u8) -> u8 { if a > b { a } else { b } }
// ......还有 u16, u32, i64, f64等等类型
```

代码复用性低，不同类型都需要定义对应的比较函数，如果使用宏定义，又无法保证类型安全。

对于rust，可以使用泛型的情况下：

```rust
fn max<T: PartialOrd>(a: T, b: T) -> T {
    if a > b { a } else { b }
}

// 使用时
max(3, 5);         // T = i32
max(3.14, 2.71);   // T = f64
max('a', 'z');     // T = char
```

其中`T` 是**类型占位符**，`<T: PartialOrd>` 表示“`T` 可以是任何实现了 `PartialOrd`（可比较）的类型”。

使用泛型的情况下不仅代码可复用，一套代码可以用于各种类型，兼顾类型安全的同时还不易出错。

## 枚举类型

rust还提供了一些在编写代码时常见且实用的枚举类型，这里主要介绍最常用的也是后续学习会接触到的两种——`Result`和`Option`。

### Result

`Result`类型是对返回结果的一层类型封装，其定义如下：

```rust
enum Result<T, E> {
   Ok(T),
   Err(E),
}
```

其中`T`为数据类型，`E`为错误类型。

`Result`类型体现了rust对代码安全性的严格要求，它常用于错误处理，其结果可能是成功(OK)也可能是失败(Err) 。如果是成功，则返回对应类型的数据值，如果是失败，则返回对应类型的错误码。

它将正确的结果跟错误显式地分离开来，且无论是哪种结果，它都会要求开发者去处理，而不会像C语言那样无论结果正确还是错误，都可以继续使用且容易忽视或混淆错误信息。

对于`Result`类型的错误处理方法，常用的有以下几种：

1. **`.unwarp()`**

对`Result`类型使用`.unwarp()`是一种简单粗暴的错误处理方法。如果结果是成功，则把数据拿出来，如果结果是错误，则**直接使系统崩溃以终止程序**，并将错误码信息打印出来。

2. **`.expect()`**

`.expect("msg")`方法在行为上与`.unwarp()`一致，区别在于引发系统崩溃时，会额外**打印指定的"msg"信息**。

```rust
let value = result.expect("初始化失败");  // 系统崩溃时会打印对应日志信息
```

3. **match匹配**

通过`match`显式得处理两种结果。

```rust
match result {
    Ok(v) => { /* ... */ }
    Err(e) => { /* ... */ }
}
```

4. **`?`向上传播**

`?` 是 Rust 的**错误传播语法**，加在返回 `Result` / `Option` 的表达式后面。

带`?`的表达式在运行出错时会将错误值返回给该表达式的调用者，`?`操作符的报错信息还可以向上沿着调用链冒泡传播，直到传播过程中错误信息被处理或最终传到`main`函数，程序终止并打印返回的错误信息。

以下面代码为例：

```rust
fn function_a() -> Result<()> {
    ...
    // 若function_b()返回错误，function_a()也随之立即返回，将错误结果向上传递
    function_b()?; 
    ...
}

fn main() -> Result<()> {
    ...
    // 若function_a()返回错误，main()也随之返回，程序退出运行并打印对应错误结果
    function_a()?;
    ...
}
```

如果`function_b()`返回的结果为`Err(e)`，则`function_a()`会将该错误结果向上传递给其调用者也就是`main()`，`main()`收到错误结果后返回`Err(e)`，**Rust 运行时**（可以理解为负责程序启动和收尾的“底层系统”）会终止程序并打印`main()`返回的错误结果。

`?`是出错了就向上传播，但也可以在传播过程中就拦截错误并处理。需要注意的是，`?` 只能在**返回 `Result` 或 `Option` 的函数**中对**返回 `Result` / `Option` 的表达式**使用。

### Option

`Option`类型类似于`Result`类型，也是一层类型封装。但`Result`表达的是结果的成功与否，`Option`则表示**数值的有无**，其定义如下：

```rust
enum Option<T> {
    Some(T),
    None,
}
```

`Option`可以是某个类型的值，也可以是空值null，通常与模式匹配结合使用，用于查询某个值的是否存在并采取相应操作。而前面所学习到的对于`Result`的展开方法，也可以使用在`Option`上。

在试图取出`Option`内部值时，编译器强制要求处理内部值为`None`的情况，否则编译报错。

这个枚举类型是用于替代其他编程语言中的空值情况，比如C语言的null指针。相较于C语言需要慎重地对待空指针，rust的`Option`可以让程序员放心安全地使用，其将空值作为系统数据类型的一部分和强制性明确处理空值情况的做法，极大地避免了C语言中空指针可能带来的问题。
